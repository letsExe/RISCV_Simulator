# 🖥️ RISC-V Simulator

Repositório desenvolvido para o trabalho da disciplina de **Organização e Arquitetura de Computadores — UNIOESTE**.

O projeto consiste em um **simulador monociclo da arquitetura RISC-V**, implementado em **C++**, capaz de ler instruções em código binário, decodificá-las, executar as operações correspondentes e exibir o estado dos registradores e da memória.

---

## 📌 Sobre o Projeto

Este simulador foi desenvolvido com o objetivo de estudar, na prática, o funcionamento interno de uma arquitetura de processador baseada no conjunto de instruções **RISC-V**.

O programa recebe como entrada um arquivo contendo instruções em formato binário, interpreta cada instrução e executa as operações correspondentes, simulando o comportamento de um processador monociclo.

Ao final da execução, o programa apresenta:

- As operações realizadas;
- O vetor de registradores;
- O vetor de memória.

---

## 🎯 Objetivo

O principal objetivo do projeto é compreender como instruções de máquina são representadas, decodificadas e executadas em uma arquitetura RISC-V.

- Representação binária de instruções;
- Decodificação de campos da instrução;
- Registradores;
- Memória de dados;
- Execução de operações aritméticas e lógicas;
- Instruções de acesso à memória;
- Funcionamento de um processador monociclo.
